# ata-Annotation-Scripts
数据标注平台进度与人效统计工具箱。A collection of Tampermonkey scripts for Data Annotation Platforms, featuring progress aggregation and QA funnel tracking.
本开源项目包含 6 款独立运行的 Tampermonkey 脚本，分为大盘进度汇总与人员质量追踪两大模块，分别适配两套不同的底层 API 架构。
核心特性：
1.采用 SPA 路由巡航雷达，完美解决单页应用跳转导致面板丢失的问题。
2.引入工业级 ID 双轨映射引擎，杜绝数据重名合并错误。
3.UI 调优：像素级固定列宽对齐、平滑的网格布局交互。
4.平台任务进度汇总（项目主进度）脚本最新的版本是1.8.0与3.8.0，分别适配get和post规则。人员双轨质量能效（供应商内部质检与我方验收两个轨道）脚本最新版本是2.6.0和2.3.0，分别适配post和get规则。
5.2.3.0版本的人员绩效双核版本在以前版本的基础上考虑到了首次验收通过和累积折损验收通过，前者可以和供应商内部质检对比来检查水分看标准对齐情况，后者则是完成任务要求后复盘时考虑人员驳回返修的次数（即额外多花的次数），由此来看人员结项质量。
