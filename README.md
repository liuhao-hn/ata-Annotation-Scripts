# ata-Annotation-Scripts

![CI](https://github.com/liuhao-hn/ata-Annotation-Scripts/actions/workflows/ci.yml/badge.svg)

数据标注平台进度与人效统计工具箱。A collection of Tampermonkey scripts for Data Annotation Platforms, featuring progress aggregation and QA funnel tracking.

## 项目概述

本仓库包含 **16 款独立运行的 Tampermonkey 脚本**，分为人员质量追踪、任务进度看板、平台适配三大模块，适配多套底层 API 架构。全部代码已在真实生产环境中稳定运行数月，本版本已完成脱敏处理。

## 核心特性

1. **SPA 路由巡航雷达**：完美解决单页应用跳转导致面板丢失的问题
2. **工业级 ID 双轨映射引擎**：杜绝数据重名合并错误
3. **时间滑窗过滤**：支持 1天 / 3天 / 7天 / 14天 / 历史全量，灵活切换数据窗口
4. **双核质量引擎**：首次验收通过率 + 累积折损通过率，前者对标供应商质检查水分，后者评估人员结项质量
5. **多格式导出**：支持本地 Excel 导出 + 协作文档智能粘贴，搭配 Python 代码一键出日报
6. **UI 调优**：像素级固定列宽对齐、平滑网格布局交互
